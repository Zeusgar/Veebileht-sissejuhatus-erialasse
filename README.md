# Veebileht-sissejuhatus-erialasse
Uku Heinamaa, Richard Anmann, Tambet Mesikäpp

## Idee
Tahame luua veebilehe, kus kasutaja sisestatud andmete põhjal loob veebileht kasutajale automaatse kutse mingile üritusele.

## Probleemid
Probleeme ei ole.

## Käitumisnormid
Vaatasime oma rühmatöö kokkulepped üle (ülesanded valmis õigeks ajaks, aktiivne osalemine, teiste kuulamine ja aitamine). Need on meile jätkuvalt olulised. Lisame juurde, et igaüks kirjutab oma commit'ile selge sõnumi.
